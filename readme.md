# 灯塔书《知识增强大模型》


## 说明
- 本仓库提供灯塔书《知识增强大模型》的补充资料



## 大模型
灯塔书中提供的许多例子，比如第二章《大语言模型》中的例子，都可以使用如下大模型产品或APP来实验。

- Deepseek： https://chat.deepseek.com
- 腾讯元宝： https://yuanbao.tencent.com/
- 豆包： https://www.doubao.com/
- 千问： https://www.qwen.ai
- ChatGPT： https://chatgpt.com
- Claude： https://claude.ai
- Gemini： https://gemini.google.com


请注意：
1. 在使用大模型本身时，请关闭“联网搜索”、”深度搜索“等功能，否则这些大模型产品会自动联网搜索，即使用了书所提到的知识增强等技术。
2. 不同大模型的版本，以及相同的大模型、相同输入都有可能会有不同的输出，这是正常现象。



## 大模型API服务

在灯塔书的第三、四、六、九等章都会用到大模型的API服务。下面是一些提供大模型API服务的平台：



- 硅基流动：https://cloud.siliconflow.cn/i/FcFXC1gt 硅基流动的CEO袁老师也大力推荐本书。也欢迎本书的读者使用硅基流动的API服务。特别的，使用上述链接（或填写邀请码：FcFXC1gt）注册硅基流动，还能获得14 元平台配额，大约为Qwen2.5-14B-Instruct 模型的 2000 万 Tokens。 特别的，硅基流动提供了免费的baai/bge-m3 的嵌入模型，在第三章向量数据库和第四章检索增强生成这两章的示例代码中可以使用。
- DeepSeek、ChatGPT、Claude和Gemini也提供了大模型的API服务
- 腾讯云、阿里云、火山云等也提供了大模型的API服务，如果已经是他们的用户，可以选择他们所提供的大模型API服务。
- 使用Ollama、Vllm等开源的推理引擎自行在本地部署大模型，并使用这些推理引擎提供的API服务。
- 使用HuggingFace、modelscope魔搭等平台的也提供了大模型的API服务
